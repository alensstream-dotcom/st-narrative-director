# AnimaDex character metadata

`animadex-characters.json` contains character names, Anima trigger strings, series names, appearance tags and post counts. It omits reference images and other metadata. It was derived from [ComfyUI-Animadex-Node](https://github.com/wrt122311/ComfyUI-Animadex-Node), whose README describes the project as MIT licensed and credits [ANIMADEX](https://animadex.net/) as its data source. The catalogue is a snapshot; the website remains the place to inspect current entries and reference renders.

Regenerate with `node tools/build-animadex-catalog.cjs <downloaded-animadex_top_characters.json>`.
