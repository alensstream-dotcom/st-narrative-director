# 叙景 · SillyTavern 剧情导演

独立新项目。读取原版智绘姬的人物档案、启用列表和工作流设置；不修改智绘姬文件，不依赖任何旧导演插件。

## 安装与使用

扩展安装链接：`https://github.com/alensstream-dotcom/st-narrative-director`

需要 SillyTavern 1.18.0、已配置的原版 st-chatu8 3.1.x，以及可用的导演 API。

1. 在酒馆扩展管理中安装本仓库，刷新页面。
2. 打开扩展设置的「叙景 · 剧情导演」→「API」。新安装默认预填用户指定的 `api-slb.krill-code.net` 与 `gpt-6-sol`，密钥不会写进公开仓库。选择酒馆已保存密钥，或在本页输入密钥后点「测试连接」；输错可直接修改、清除和重试。本页密钥只留在内存，刷新后需重新输入；想持久使用，请先保存到酒馆密钥管理再选择。
3. ComfyUI 默认使用用户指定的 Miaomiao Harem 配套工作流：12 步、CFG 2.5、Euler/simple、896×1152、加速 LoRA 0.8、shift 3。来自服务器保存的 `anima加速.json`，不是之前 JANIMA 的 8 步配置。也可明确选择读取智绘姬当前工作流。所需模型缺失会报错，不会自动换模型。
4. 「人物」页显示当前聊天的人物与智绘姬档案关联，可查看固定外貌、保存别名、改变关联和回滚锁定。新人物分析后渐进建档；手工改过的原档案不会被自动覆盖。
   同页可查看该人物关联的智绘姬服装预设。只有确认生图或自动镜头获准后，且服装有剧情原文依据时，才会自动复用/新增对应服装；仅打开预览不会建服装。不会修改智绘姬的全局人物或服装启用列表。
   仅有服装类型（如“校服”）时复用通用类型 Tag，款式细节可变化；剧情明确给出颜色、材质、徽章等细节时按该时点建具体款式，不把旧款式套回当前剧情。人物卡片的「按当前外观筛选 ANIMADEX」会把已知发色、眼睛、发长和性别带到 [ANIMADEX](https://animadex.net/?mode=characters) 候选页；浏览后可将选定的角色 Tag 保存为视觉原型。ANIMADEX 跨域限制使插件不在生图链路实时调用它，避免网络延迟和第三方故障。
5. 「生图」页开启「自动导演」后，回复流式生成期间按完整剧情片段增量分析并提前提交第一张；结尾仅处理未分析的新增剧情及保留候选，不重跑已分析全文。每轮至多两张，可以不画，也不为同一动作的后续姿势凑第二张。独立导演 API 会产生额外 token 费用；实际图片显示时间仍取决于导演 API 和 ComfyUI 耗时。
6. 手动长按/拖选助手正文，点击浮出的「生成图片」。多事件选段可先选具体瞬间，再编辑英文正负提示词并为本张选择后端/工作流；点击「确认生成」后才发送图片任务。关闭预览不会出图，手动次数不限。
7. 图片显示在对应文字之后。图片旁可查看、重绘、锁定或解除人物固定外貌；任务页可查看失败原因和重试。

自动默认关闭，避免安装后未经确认发送私人剧情或消耗生图费用。手机访问电脑 ComfyUI 时沿用智绘姬地址：如果酒馆服务器在手机上，`127.0.0.1` 指手机自身，应在原版智绘姬设置电脑局域网地址。本插件不自动修改它。

## 当前范围

- 自动与手动共用有原文依据的单一镜头结构；英文提示词；不要求正文模型输出标签。
- 自动排除仅男性/性别不明确主体，手动不限制；自动名额不约束手动。
- 人物自动关联原版智绘姬当前已启用的同名档案或本聊天已关联档案；不擅自关联未启用的同名旧角色。缺失时新建独立标记的角色，不更改启用列表。固定外貌与时点服装分开。
- 图片使用酒馆原生图片存储接口，聊天仅保存图片路径、锚点和必要元数据，不存 base64。
- ComfyUI 使用所选配套工作流或智绘姬配置的独立任务快照；不改原版配置。配套模板仅替换正负词、随机种子和输出文件名前缀，不包含用户原提示词。未支持的占位符/跳过节点会明确报错。
- 云端目前仅适配智绘姬 Banana 的 OpenAI 兼容聊天式图片响应；Imagen、原生 Grok 图片接口、视频不在当前支持范围。

## 重要限制

真实测试结果与未完成项见 `TEST_REPORT.md`；当前代码的正式酒馆安装与 Android 真机验收不能由桌面模拟代替。

- 原版没有足够的无补丁公开接口。根据用户“不修改原版”的要求，执行适配器使用酒馆原生 ComfyUI/图片接口，不冒充智绘姬内部任务队列；不共享其私有缓存/查看器。
- 当前形象锁定是固定外貌描述锁定，不是已验证的人脸参考锁定。当前 Anima 工作流没有已验证参考分支；不会假装参考图已经注入。跨图脸部高度一致尚未达到任务书完整目标。
- 通用服装 Tag 只约束服装类别，不能保证某件衣服或配饰跨图像素级一致；剧情指定细节仍由模型按提示词绘制，成图可能失误。
- 不自动下载 LoRA，不强行套用其他动漫人物 Tag。插件带 10 个高置信离线候选，并提供按外观筛选 ANIMADEX 的入口；从候选中挑选并确认 Tag 仍由用户决定，不会把外观相似误认为同一身份。
- 切换聊天/Swipe、删除或修改原选段使未完成任务过期；已发给后端的请求可能继续耗算力。插件不向 ComfyUI 发送可能中断他人任务的全局 interrupt。
- 独立导演不会给正文模型增加长期记忆提示，也不替代角色扮演长期记忆插件。
- Android 真机手势和未配置云端服务必须单独实测，桌面移动视口不等于真机通过。

## 数据与卸载

设置位于 `extensionSettings.narrative_director_v1`；消息锚点/状态位于消息 `extra.narrative_director_v1`。原文 `mes` 不被重写。角色由智绘姬 `characterPresets` 管理，新建档案带 `directorOwner` 标记；有依据的剧情服装进入其 `outfitPresets`，只关联对应人物，图任务保存服装引用。用户手工改过的预设不会被自动覆盖。

已保存密钥只引用酒馆中的 secret ID；本页密钥留在页面内存，不写聊天、任务或扩展设置。它可以用于 DeepSeek、OpenAI 或兼容接口，且与填写时的地址绑定。切换到已保存密钥会立即丢弃本页密钥。不开启自动导演则不自动上传剧情；手动分析只在点击选段按钮后进行。

卸载扩展不会删除正文、图片或原版人物资料。若要清理，先导出聊天/智绘姬设置，再仅删除本插件命名空间及明确标记的新档案。

开发测试：`npm test`。浏览器测试需 Playwright 和 Edge，`node tools/browser-test.cjs`；加 `--real` 会调用当前真实导演 API 和 ComfyUI，产生费用/算力消耗，但使用独立测试剧情、不保存酒馆聊天/设置。
