# 叙景 · SillyTavern 剧情导演

独立的 SillyTavern 扩展。导演只负责从剧情选择画面、维护人物和服装状态、生成英文提示词；原版智绘姬 `st-chatu8` 负责识别 `image###...###`、自动点击、ComfyUI 生图和原文下方显示。**不修改智绘姬源码，也不把生图提示词写入聊天正文。**

## 安装

扩展安装地址：`https://github.com/alensstream-dotcom/st-narrative-director`

1. 在酒馆安装原版智绘姬 3.1.2 和本扩展，刷新页面。
2. 打开「叙景 · 剧情导演」→「API」，直接填写兼容接口地址和 API Key，点击「连接并获取模型」，从列表选择模型；也可以直接在「模型名称」手填 ID，再点「测试当前模型」。兼容接口示例地址为 `https://api-slb.krill-code.net/v1`，模型示例为 `gpt-6-sol`。直接输入的密钥仅在当前页面内存中，刷新后需重填；如要跨刷新使用，可在「更多连接选项与密钥管理」中选择酒馆已保存的密钥。密钥不在仓库或普通扩展设置中。
3. 打开「生图」，点击「应用智绘姬配套设置」，再点「检查 ComfyUI」。这会新增并选中专用工作流，设置 `image###` / `###`、智绘姬自动点击和酒馆代理模式。已有工作流、人物及服装预设保留；「恢复应用前设置」可回退本次变更。
4. 自动生图模型位于「高级」中，默认跟随完整分析模型。打开自动选镜头后，导演在回复生成期间旁路分析，优先交付可校验的英文提示词，随后补齐同一镜头的人物与服装资料。最多两张；已有中途镜头时不在结尾重扫补图。若此前没有合适镜头，结尾尝试一个有原文依据的画面；API 失败或没有可画内容时不会编造画面。提示词交付后，图片完成时间仍取决于智绘姬与 ComfyUI。
5. 手动生图：长按/拖选助手剧情中的一段文字，点「生成图片」，查看并可编辑英文提示词，确认后在该段下方交给智绘姬。手动次数不受自动上限限制。

智绘姬当前配套工作流使用 `miaomiaoHarem_29BBETA10.safetensors`、Anima Turbo LoRA 0.8、12 步、CFG 2.5、Euler/simple、896×1152。工作流图中的 UNet 加载器才是真实模型；智绘姬侧边的 `MODEL_NAME` 旧 checkpoint 下拉框可能不显示 UNet 文件，不能用它判断实际执行模型。ComfyUI 任务历史可核对。

## 模型列表与正文推理

酒馆的兼容接口代理在服务商模型目录暂时失败时，可能返回 HTTP 200 错误包。插件会短暂重试一次；本页直接输入的兼容接口密钥还会尝试直连 `/models`，并保留本页上次成功的模型列表。若手机浏览器阻止直连跨域请求，仍可手填模型 ID 并用「测试当前模型」检查。读取模型列表不保存酒馆全局设置。正文推理强度保持用户设定的 max；若正文模型耗尽输出上限而没有生成可见剧情，导演不会从隐藏思考中虚构画面。

## 人物与迁移

导演从角色卡、当前剧情、已激活世界书和智绘姬现有档案提取有证据的固定外貌与时点服装。新人物渐进建到智绘姬人物管理，服装只关联对应人物，不改其全局启用列表；用户手改的档案不被自动覆盖。人物页可搜索本地的 [ANIMADEX](https://animadex.net/) 角色目录快照，共 36,492 条，不限于少数内置示例；按英文角色名、作品名或已知外貌挑选后，一键使用该角色的 Anima 触发串。内置小范围候选只在有证据且唯一匹配时自动套用；全量目录匹配常有大量相似人物，需要用户选择。Tag 用于外貌参考，当前剧情的衣服、动作和地点仍以正文为准。

单人图生成后，点击图下「保存形象」，再确认人物。插件把固定外貌、角色触发串和照片写入智绘姬的人物档案；若当前剧情的服装已有证据，也把服装文字和同一张照片关联到该人物的智绘姬服装预设。照片存到酒馆服务器上的智绘姬配置图片区，手机与电脑打开同一酒馆时都能读取。已有用户编辑的外貌和照片提示词不会被自动覆盖；换装和动作不随外貌锁定。多人合照不会整张保存为某个单人的照片。

手机连接电脑上的酒馆时，让智绘姬使用「酒馆」客户端与 `http://127.0.0.1:8188`，这里的回环地址由电脑上的酒馆服务器代理访问 ComfyUI。若酒馆服务器运行在手机上，则需改成电脑的局域网地址。

换酒馆服务器时，安装两个扩展，用智绘姬右上角的原生导出/导入迁移其人物、服装和其他设置；本扩展内置配套工作流，也可以在新设备再次点击「应用智绘姬配套设置」。连接同一酒馆服务器的手机和电脑可读取本扩展保存到服务器的智绘姬照片。聊天内的导演状态随酒馆聊天备份迁移；API 密钥应通过各设备的密钥管理单独设置。不要把含私人资料的智绘姬完整导出文件发到公开仓库。

## 验证与限制

`npm test`、`node tools/chatu-dom.cjs` 可检查规则与两个原文位置按钮的刷新恢复。`node tools/chatu-integration.cjs --wait-image` 会实际调用 ComfyUI 并消耗算力；使用测试消息并在结束时清理。详情见 [TEST_REPORT.md](TEST_REPORT.md) 和 [INTEGRATION_NOTES.md](INTEGRATION_NOTES.md)。

已经在本机 Edge 移动视口测试智绘姬按钮、自动点击和真实图片回填；**尚未在安卓真机验证触屏选区**。图片模型仍可能偏离道具、空间关系或脸型，文字 Tag 锁定不是像素级人脸参考。新插件不替代完整的角色扮演长期记忆系统。自动分析会把选中或新生成的剧情片段发给所配辅助 API，正文模型提示词本身不增加生图标签。
