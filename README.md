# 叙景 · 世界书助手 0.6.3

主 API 随正文输出普通、非露骨剧情的插图指令，智绘姬负责生成。世界书负责画面选择与事实对齐，叙景只补足选段操作和诊断。

## 使用

1. 下载 [Anima-Story-Safe-v3.json](worldbooks/Anima-Story-Safe-v3.json)，导入酒馆世界书，在当前角色或聊天启用。停用旧 Anima 生图规则书，包括上一版 v2，避免规则冲突；保留原文件作备份。
2. 数据库原有的记忆注入照常使用。新规则根据主 API 实际收到的摘要维持人物外貌与衣着，以当前正文修正过时记录。
3. 标记使用 `image###` 和 `###`，智绘姬开启“AI 自主分辨率”。若要让竖、横、方图比例真正生效，导入下载目录中的动态比例工作流；原工作流的画布写死为竖图。自动出图需要智绘姬的普通自动点击功能开启。
4. 如需选段补图，在酒馆扩展中安装/更新本仓库并刷新页面。点击回复下的“选段补图”，或选中文字后使用浮动按钮。预览原句和英文提示词后交给智绘姬；叙景会核对并触发这条手动生成按钮，避开智绘姬已有按钮的自动点击状态差异。

扩展安装地址：https://github.com/alensstream-dotcom/st-narrative-director

世界书可以独立使用，不必安装叙景。扩展设置入口改为“叙景 · 世界书助手”。

## 这次改了什么

- 用单一核心条目整理画面锚定、事件覆盖、人物衣着和输出格式，减少原文件大量常开规则的竞争；补入通用外貌、场景 Tag 参考。
- 每图对应已经发生的一个瞬间；当前动作、对象和空间关系必须一致。即使人物仍在同一位置，主动/被动、手部接触或道具状态改变也要识别为新节拍，值得配图时在新动作后另出图。
- 无换装就沿用，明确变化只修改变化部分；不把最新总结里的服装倒灌到旧镜头。
- 不同角色优先使用已有记录中最能区分的发型、眼型、瞳色和脸部特征；同一角色跨图沿用同一组英文特征词。
- 使用 Anima 的 `safe` 标签；只有资料中已有经核对的角色与作品 Tag 时才使用，不把少数角色当成完整目录。[AnimaDex](https://animadex.net/) 可查触发词，世界书不会自行上网查找。
- 删除独立 API 与模型设置、自动导演队列、重复人物/服装记忆、原型目录、工作流接管及旧测试工具。
- 保留选段补图、提示词预览、指令诊断与旧图片显示。以前保存在智绘姬的人物照片、服装、工作流和聊天不作清除。

正文模型、推理强度、回复长度设置均不修改。手动补图沿用当前主 API，不另设密钥；这仍是一次额外模型请求，只有点击分析时才发生。

## 数据库如何配合

“数据库”在这里是角色、衣着和剧情的事实摘要，不假定你安装了哪一种插件。自动插图使用数据库已经注入主 API 上下文的记录；世界书不会自己读取文件或浏览器存储。

选段补图带入原句、该段之前的有限近期正文和当前角色卡。可选的资料框可以放入相关数据库摘要；本版没有接通未确认的数据库接口，不声称自动获取全部记忆。第三方扩展仍可能通过酒馆的提示词事件注入自己的内容，尤其给旧楼层补图时要注意时间一致性。

建议在现有数据库里保存的字段和旧段落补图的用法，见 [人物与服装资料格式](CHARACTER_REFERENCE_TEMPLATE.md)。
